# RedOx Engine — статус

Обновлено 2026-10-18 (после пяти волн субагентов, игры Foxfire и исправления кластерного света). Подробный план и журнал выполнения — `docs/ROADMAP_STAGE_0_1.md`,
история изменений — `CHANGELOG.md`, устройство — `ARCHITECTURE_REALITY.md`.

## Готово

- Этап 0 (гигиена): лицензии, линтеры (`clippy -D warnings`, `missing_docs`), `cargo deny`,
  аудит `unsafe` в ECS и Miri, интеграционные тесты, бенчмарки, ADR, документация.
- 1.1 Зависимости: wgpu 30, egui 0.36, rapier 0.36, kira 0.12, glam 0.33, winit 0.30 и др.
- 1.2 Рендер: компилятор графа кадра и декларация кадра (сверяется с кодом тестом), кэш
  пайплайнов на диске (Vulkan), проверка шейдеров при правке и пересборка 11 проходов без
  перезапуска (`Renderer::reload_shaders`), загрузка KTX2/BCn на GPU (`Texture::from_ktx2`).
- 1.3 ECS и ядро: `Commands` (в диспетчере сбрасываются между стадиями), порядок систем
  `before/after`, `run_if`, `par_for_each_mut`, `#[derive(Reflect)]`, состояния приложения с
  `OnEnter/OnExit`, хуки `on_add/on_remove`.
- 1.4 Ассеты: GUID и `.meta`, `.pak` v2 со сжатием LZ4, `AssetSource` (папка/pak), счётчики ссылок
  и выгрузка, зависимости, бюджет завершённых загрузок за кадр, KTX2/BCn, `redox_cook`
  (`pack --compress --incremental`).
- 1.5 Мир и ввод: сохранения (`SaveManager`), `world.bin` (postcard + индекс ячеек), переназначение
  клавиш, контексты ввода, геймпады (gilrs), текст и IME.
- winit: замыкание гоняется через `ApplicationHandler` (`RunClosure`), общих
  `#![allow(deprecated)]` нет.

### Состояние на вечер 2026-10-17 (ранее)

Закрыто: этапы 0–1, весь план текстур (фазы 0–5 и добивка), анимационный граф, игровой UI, прототип Courier.
Остановились на проверке Courier владельцем в живую: меню, управление, HUD, пауза, стриминг и RU/EN работают;
найдены и исправлены два бага (цилиндры персонажа с обратной намоткой граней; свечение bloom старого размера,
остававшееся на экране после ресайза окна — баг рендерера, затрагивал все примеры и редактор).
Все проверки зелёные: fmt, clippy `-D warnings`, `cargo test --workspace`, doc, deny, golden-кадры.
Примеры: `courier`, `skinned_demo` (он же визуальный регресс), `dino_runner`, `dino_game`; редактор `redox_editor`.
Репозиторий на GitHub обновлён 2026-10-17 (первый push за долгое время); позднее работа закоммичена локально.
Главные слепые зоны: IME (в Courier не подключён), редактор и рендер мало покрыты тестами, нет CI; звук и геймпад Courier
проверены тестами логики и коротким запуском, вживую не прослушивались. Другие ОС, GPU и DX12/Metal вырезаны из плана.

## Новое в этом заходе

- **Добивка текстур.** Покрытие новых модулей: `redox_asset` 81–99 % строк, стример 92 %, IBL 99 %. Golden-кадры
  IBL из KTX2 и сошедшегося стриминга. BasisLZ и UASTC+Zstd проверены на 6 файлах Khronos (ETC1S и UASTC одной
  картинки расходятся на 2,2/255).
- **Анимационный граф** (`redox_anim::graph`): параметры и триггеры, state machine с кроссфейдами и exit time,
  1D blend tree с синхронизацией фаз, слои с маской, root motion, события; serde-данные. 9 тестов.
- **Игровой UI** (`redox_ui::game`): раскладка (column/row/stack/якоря/fill/fit), масштаб от 1920×1080 с безопасной
  зоной, локализация RU/EN с падежными формами, навигация фокусом, стек экранов, отрисовка через egui. 18 тестов.
- **Courier** (`cargo run --release --example courier -p redox_core`): третье лицо, граф анимации (идле/ходьба/бег по
  blend tree, машущая рука на отдельном слое, скорость из root motion), меню/HUD/пауза/победа на двух языках,
  уровень и текстуры из `.pak`, стриминг текстуры земли 2048 px. 16 тестов правил и раскладки. Клавиши F1–F4 —
  отладочные переключатели bloom/TAA/SSAO/теней.
- **Исправлено в рендерере:** привязки тонмаппинга после ресайза читали bloom старого размера (тест `resize_bloom`).

## Куда дальше (предложение, по приоритету)

> Пункты 1 и 3 ниже частично выполнены (Courier: сохранение, звук, геймпад; WASM: прототип и хост-API v1a); актуальный
> порядок — в «Следующей волне» плана выполнения.

1. **Игра как стенд для движка.** Довести Courier до цикла «меню → игра → победа → сохранение»: сохранение лучшего
   времени (`SaveManager`), звук (шаги, подбор монет через `redox_audio`), настройки (язык, громкость), подключение
   геймпада (`GamepadsState`) и навигация меню стиком. Это закрывает слепые зоны ввода и проверяет API на живой игре.
2. **Анимация, следующий уровень:** загрузка скелета и клипов из glTF в граф, blend space 2D (направление+скорость),
   аддитивные слои, события клипов (шаги), IK ног на неровной земле, GPU-скиннинг.
3. **WASM-скриптинг:** прототип (`wasmi` или `wasmtime`): модуль с `on_update(dt)`, малое API хоста (трансформ,
   ввод, события, лог), замер стоимости вызова; логику монет Courier вынести в модуль как проверку.
4. **Редактор из просмотрщика в инструмент:** сохранение/загрузка сцены, undo/redo, импорт ассетов (кнопка PNG→KTX2),
   показ состояния стриминга и типа сжатия в панели ассетов, превью графа анимации.
5. **Качество и инфраструктура:** покрытие тестами рендера и редактора (измерить `llvm-cov`), smoke-тест редактора,
   вопрос про CI (отложен владельцем), разбиение `graph.rs` (975 строк) и `layout.rs` (811) по лимиту 800.
6. **Рендер:** отложенное по решению владельца (горячая перезагрузка VG-compute и IBL, вывод зависимостей графа
   кадра и память по графу), SDF-страницы из стриминга, бюджеты памяти для мешей/VG по образцу текстур.
7. **Далее (месяцы):** DDGI на трассировке лучей, граф материалов Substrate, игровой UI: шрифты/текст-ввод/IME,
   навигация (navmesh), физика (joints, ragdoll), сеть.

## Текстуры KTX2 (готово, 2026-10-17)

- Zstd и Basis Universal (UASTC, ETC1S), кубмапы, массивы, IBL из KTX2 (`redox_cook bake-ibl`),
  приоритетная очередь загрузки, потоковая догрузка mip и `TextureStreamer` с бюджетом памяти.
  План и итоги: [`docs/PLAN_TEXTURES.md`](docs/PLAN_TEXTURES.md), решение: [`docs/adr/0004-ktx2-basis-streaming.md`](docs/adr/0004-ktx2-basis-streaming.md),
  как готовить ассеты: [`docs/ASSETS.md`](docs/ASSETS.md).
- BasisLZ и UASTC+Zstd из сторонних KTX2 (Khronos KTX-Software, 6 файлов) проверены: грузятся, ETC1S и UASTC одной картинки расходятся на 2,2/255. Данные Basis из недоверенных источников защищены контрольными суммами,
  структурными проверками и `catch_unwind`, но C++ транскодер остаётся внешним кодом.

## Отложено (решение владельца, 2026-10-17)

- Горячая перезагрузка compute-части VG (`vg_cull`, Hi-Z) и IBL: состояние нельзя пересоздать на лету, нужен перезапуск.
- Граф кадра: автоматический вывод зависимостей из кода проходов и выделение памяти транзиентных текстур по графу.
- Другие платформы, DX12/Metal, проверка на другом железе — вырезано из плана (2026-10-17), только Windows + Vulkan.

## Не сделано

- Пересборка compute-части VG (`vg_cull`, Hi-Z) и IBL при правке шейдера: нужен перезапуск.
- DDGI на трассировке лучей, SDF-страницы из стриминга, полный граф Substrate. GPU-скиннинг есть, пакетный режим
  быстрее CPU (100 персонажей, dev-профиль: 1,6 против 22 мс).
- CI не используется (решение владельца); файлы в `.github/` — заготовка, на GitHub не запускались.
- Foxfire (`cargo run --example foxrun -p redox_core --release`): проверен кадрами без окна и автопилотом, меню, HUD и звук вживую не смотрелись.
- Не сделано: тангенты и морфы в скиннинге, SDK для скриптов, контроллер персонажа 2.0 (B5), адаптивная музыка.
- IME в играх не проверен. Геймпад и звук в Courier подключены, но проверены только тестами логики и запуском на 20 с
  без падений. Предыдущую версию Courier владелец проверил в живую (меню, управление,
  HUD, пауза, стриминг); остальные примеры и редактор запускались по 12 секунд без паник и ошибок валидации.

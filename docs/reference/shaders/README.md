# Справочные шейдеры

Файлы в этой папке **не компилируются** движком. Это отдельные копии кода, который целиком
встроен в `crates/redox_render/shaders/pbr.wgsl` и `vg_resolve.wgsl` (в WGSL нет `#include`).
Они нужны как читаемый «канонический источник» при ручной синхронизации блоков.
Окончательное решение (модульные шейдеры) — задача 1.2.4 в `docs/ROADMAP_STAGE_0_1.md`.

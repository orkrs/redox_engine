# Известные ограничения (исход 📌 финальной волны)

Запись добавляется, когда задача не прошла приёмку за две попытки агента и одну попытку координатора (см. `FINAL_WAVE.md` §1).
Формат: ID — симптом — измеренное число — обходной путь — что нужно для устранения.

| ID | Симптом | Число | Обходной путь | Что нужно для устранения |
|---|---|---|---|---|
| NAV-05 | 200 агентов не укладываются в 1 мс | 2,48 мс на update (было 9,5; радиус соседей 5→2 м); на 1 м — 1,07 мс; только путь без избегания — 0,46 мс | оставить 2 м (качество избегания), держать число активных агентов ≤ ~80 на кадр | избегание на 20 Гц и усыпление агентов, либо своё следование по коридору + dodgy_2d (нужна прямая зависимость и решение владельца) |
| PHY-07 | нет оконного `ragdoll_demo` с лисой Foxfire и клавишами R/T | есть headless-пример с кубом-человеком | запуск `ragdoll_demo` из консоли | оконная версия поверх foxrun (~800 строк) |
| RFL-01 | захват проб отражений в LDR | грани проходят пост-цепочку (tone mapping, bloom, TAA) и пишутся в формат поверхности | отражения яркого света обрезаются; для сцен без ярких источников незаметно | линейный HDR-выход граней минуя пост-цепочку (правка frame/post) |
| VG-04 | прокси HLOD одного цвета на ячейку | средний цвет вершин | достаточно для дальних ячеек | атрибут цвета вершины в `Vertex` или отдельный пайплайн |

# Известные ограничения (исход 📌 финальной волны)

Запись добавляется, когда задача не прошла приёмку за две попытки агента и одну попытку координатора (см. `FINAL_WAVE.md` §1).
Формат: ID — симптом — измеренное число — обходной путь — что нужно для устранения.

| ID | Симптом | Число | Обходной путь | Что нужно для устранения |
|---|---|---|---|---|
| NAV-05 | 200 агентов не укладываются в 1 мс | 2,48 мс на update (было 9,5; радиус соседей 5→2 м); на 1 м — 1,07 мс; только путь без избегания — 0,46 мс | оставить 2 м (качество избегания), держать число активных агентов ≤ ~80 на кадр | избегание на 20 Гц и усыпление агентов, либо своё следование по коридору + dodgy_2d (нужна прямая зависимость и решение владельца) |
| RFL-01 | захват проб отражений в LDR | грани проходят пост-цепочку (tone mapping, bloom, TAA) и пишутся в формат поверхности | отражения яркого света обрезаются; для сцен без ярких источников незаметно | линейный HDR-выход граней минуя пост-цепочку (правка frame/post) |
| VG-04 | прокси HLOD одного цвета на ячейку | средний цвет вершин | достаточно для дальних ячеек | атрибут цвета вершины в `Vertex` или отдельный пайплайн |
| GI-01 | свет просачивается через тонкую стену (0,2 м при шаге проб 0,5 м) | после 300 кадров тёмная комната 66,9 против 191,3 (35 %, цель 5 %); на 60 кадрах 19 % | не ставить стены тоньше шага проб рядом с ярким источником; толстые стены держат | более плотный шаг проб у стен, проверка рабочего Chebyshev по текстуре видимости, смещение проб с учётом весов |
| GI-01 | оттенок от цветных стен слабее CPU-эталона | R/G на 0,7 м от красной стены 1,008 в кадре против ≈1,04 по эталону | цветной свет заметен вблизи стен | сверка вклада bounce с эталоном по точкам (тест `the_gi_matches_the_cpu_reference_within_tolerance` не написан) |

| GI-02 | атлас карточек (64 МиБ) вне `MemoryBudget`; эмиссия карточки скалярная | — | — | регистрация в бюджете, цветная эмиссия |
| GI-06 | большой меш — один кирпич ≤ max, не разбивается на кирпичи | стример подключён (`GiSdfStreamingPlugin`), GPU-тест зелёный | меш не больше `--max-world-size` | разбиение большого меша на кирпичи в `redox_cook bake-sdf` |
| GI-03, GI-05 | ⛔ не делаются (нет подтверждённой нужды / экспериментальный ray query) | — | — | см. спеки |
| MAT-05 | SSS блюрит весь цвет, а не диффузную часть; один профиль на кадр | блюр после TAA, маска из префасса нормалей | умеренный `radius_mm` | второй цветовой вывод основного прохода (исходный шаг 3) |
| MAT-06 | преломление без размытия по шероховатости; нет реактивной маски TAA для стекла | глянцевое стекло, дрожание на движении возможно | — | мипы копии цвета сцены, второй вывод прозрачного прохода |
| GI-04 | отражения из кэша шейдятся по пробам (мягкие), без радиации карточек | отражение цвета стен есть, детали карточек нет | — | LOD карточек и мипы атласа радиации |
| MAT-07 | графовые материалы в VG resolve: UV = 0, вершинное смещение не применяется, слоты сверх 8 не рисуются | VG-пиксели графового слота получают поверхность графа с UV 0; до 8 графовых слотов на кадр | не использовать UV-зависимые узлы на VG-мешах; держать ≤ 8 графовых материалов | UV в VG resolve (буфер UV уже есть, нужна выборка по мешлету); отдельный буфер смещений |

| PST-06 | туман и вся постобработка работают только при включённом TAA | цепочка эффектов живёт в ветке TAA (`renderer/frame/post.rs`); с TAA выключенным туман не рисуется | включать TAA (`enable_taa(true)`) | вынести цепочку эффектов из ветки TAA |

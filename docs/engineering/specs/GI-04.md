# GI-04 — G4: шероховатые отражения из кэша (SDF + карточки + пробы)

- **Статус:** не начат.

- **Размер:** 4 шага (S, M, M, S) ≈ 9 дней. **Крейт:** `redox_render`. **Зависит от:** GI-02 (радиация карточек, глобальный SDF), RFL-01 (пробы отражений как запасной вариант), PST-05 (SSR, готов). **Блокирует:** —.
- **Модель:** haiku по шагам 1, 4; шаги 2–3 (шейдер трассировки, сведение с SSR) — haiku с проверкой координатора.
- Цель плана: единая система света и отражений; острые отражения — SSR, шероховатые и «за экраном» — из кэша. **Не входит:** аппаратные лучи (G5), отражения прозрачных поверхностей, отражения динамических объектов (их нет в SDF/карточках; остаются в SSR).

## Суть
Цепочка отражений после задачи: **SSR (экран) → SDF + карточки (мир, статика) → пробы RFL-01 → глобальный IBL**. SSR (`post/ssr.rs`, PST-05) отражает только то, что есть на экране и только на гладких поверхностях (`max_roughness` 0,5). Остальное сейчас берётся из глобального IBL в `pbr.wgsl`.
Новый проход `post/gi_reflect.rs` в цепочке эффектов: для каждого пикселя с `roughness ∈ (0.05, 0.7]` и металлом/диэлектриком с заметным Френелем бросает один отражённый луч (конус по шероховатости), трассирует его по глобальному SDF, в точке попадания читает радиацию карточки (`card_radiance`, GI-02) с уровнем детализации по ширине конуса; промах → цвет не добавляется (остаётся IBL). Результат смешивается с цветом сцены там, где SSR не нашёл попадания.

## Что уже есть (проверено чтением)
- Цепочка: TAA → SSR → motion blur → DoF → туман → bloom → tone mapping (`post/post_fx.rs`, `PLAN_LIGHTING.md` §8). SSR читает `normal` (xyz мировая + глубина вида в `w`) и `surface` (roughness `r`, metallic `g`, `Rg8Unorm`); функции `roughness_weight`, `edge_fade`, `fresnel_weight`, `ssr_weight` — чистые Rust-копии шейдера (`ssr.rs`).
- Выход SSR: смешение с цветом по весу `ssr_weight` (максимум 0,9) → цвет, где SSR промахнулся, остаётся как есть (в нём уже IBL).
- Глобальный SDF и радиация карточек — GI-01/GI-02; функции `trace_world`, `card_radiance` вынесены в `shaders/gi_common.wgsl` (GI-02/03).

## Шаг 1 — чистая математика (S, без GPU)
`src/post/gi_reflect.rs`:
```rust
/// Parameters of the cache reflections.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct GiReflectSettings {
    pub min_roughness: f32,   // 0.05: smoother surfaces are left to SSR / probes
    pub max_roughness: f32,   // 0.7
    pub max_distance: f32,    // 30.0 m
    pub intensity: f32,       // 1.0
}
/// Cone half-angle (radians) for a perceptual roughness: `atan(roughness² * 0.5)` clamped to [0.01, 0.6].
pub fn cone_half_angle(roughness: f32) -> f32;
/// Mip/LOD of the card sampled at distance `t` along a cone: `log2(max(2 * t * tan(half_angle) / texel_world, 1))`, clamped to `[0, 4]`.
pub fn card_lod(t: f32, half_angle: f32, texel_world: f32) -> f32;
/// Weight of the cache reflection: `roughness_range * (1 - ssr_hit_weight) * fresnel_weight(n_dot_v, metallic) * edge`, clamped to [0, 1].
pub fn cache_weight(roughness: f32, settings: &GiReflectSettings, ssr_hit_weight: f32, n_dot_v: f32, metallic: f32) -> f32;
```
`roughness_range`: 0 вне `[min, max]`, плавный переход (smoothstep) на 20% краёв диапазона.

## Шаг 2 — трассировка отражённых лучей (M)
- `shaders/gi_reflect.wgsl` (compute 8×8, по пикселю половинного разрешения — настройка `half_res`, по умолчанию true): из `normal`/`surface`/глубины восстановить позицию и нормаль; отражённый вектор `r = reflect(-v, n)`, для шероховатости — слегка рассеять по конусу (Хэммерсли, 1 луч, индекс по `frame` + пиксель; шум снимет шаг 3); сферический шаг по `distance_tex` GI-01 (до 64 шагов, `max_distance`, шаг с учётом ширины конуса `max(d, t*tan(a))`); в попадании — `card_radiance` на LOD `card_lod(…)` (билинейно + мип-цепочка атласа излучения: **добавить 4 мипа в `card_atlas.radiance`** и пересчёт мипов после обновления четверти — compute `gi_card_mips.wgsl`, 2×2 усреднение) ; результат `reflect_tex: Rgba16Float` (rgb радиация, a = вес попадания 0/1).
- Лучи, вышедшие за пределы объёма SDF, считаются промахом (a=0).
- Объекты без карточек (динамические) в SDF отсутствуют — луч их не видит, документировать.
Тесты (GPU, `tests/gi_reflect.rs`):
```rust
#[test] fn a_floor_in_front_of_a_red_wall_reflects_red() { /* глянцевый пол, красная стена за камерой — вне экрана: пиксель reflect_tex r > 2g, a = 1 */ }
#[test] fn a_ray_into_the_open_sky_is_a_miss() { /* a == 0 */ }
#[test] fn rougher_floors_sample_a_blurrier_card_lod() { /* дисперсия значений на шахматной карточке убывает с roughness */ }
#[test] fn the_card_mips_average_the_four_children() { /* 4 текселя 0/1/0/1 -> 0.5 */ }
#[test] fn dynamic_objects_are_absent_from_cache_reflections() { /* куб без карточек не виден: a == 0 там, где он должен отражаться */ }
```

## Шаг 3 — сведение с SSR и шумоподавление (M)
- `post/gi_reflect.rs` — `GiReflectPass`: после SSR в `PostFx` (**ПРОВЕРИТЬ** структуру цепочки `ChainFrame`/порядок в `post_fx.rs` и добавить стадию «gi_reflect» между SSR и motion blur, как PST-05 добавил SSR); SSR должен отдать `ssr_hit_weight` (сейчас он применяет вес внутри шейдера и не сохраняет → дополнить `ssr.wgsl` вторым выводом `Rg8Unorm`/`R8Unorm` с весом попадания, **только если gi_reflect включён**, иначе кадр побитно прежний).
- Шумоподавление: временное накопление с репроекцией по скорости (`hysteresis = 0.9`, как GI-03 шаг 3) + 3×3 билатеральный фильтр по глубине/нормали/шероховатости; `reflect_tex_history` ping-pong; пересоздание в `resize.rs`.
- Смешение: `scene = mix(scene, scene_without_ibl_spec + reflect, w)` невозможно (IBL уже в цвете): принять упрощение PST-05 («заменяет часть, а не добавляет»): `scene = mix(scene, reflect.rgb * fresnel, cache_weight)`; комментарий об упрощении в модуле, как в `ssr.rs`.
- Настройка: `Renderer::set_gi_reflections(Option<GiReflectSettings>)`; `None` — кадр побитно прежний; работает только в TAA-ветке (как SSR).
Тесты (GPU, `tests/gi_reflect_scene.rs`):

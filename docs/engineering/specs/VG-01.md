# VG-01 — Виртуальная геометрия, D1: иерархия кластеров (DAG) в cook, пошагово

- **Размер:** 5 шагов (S, S, M, M, S) ≈ 10–12 дней в сумме; **каждый шаг — отдельный слияемый коммит.** **Крейт:** `redox_render` (`virtual_geometry/`), мелкая правка `redox_cook`. **Зависит от:** ничего. **Блокирует:** VG-02, VG-03.
- **Модель:** haiku по шагам 1–2 и 5; шаги 3–4 (упрощение, швы) — haiku **с проверкой координатора после каждого шага** (самые тонкие места: трещины, ошибки).
- **Текущий VG остаётся**: плоские уровни LOD (`lod.rs`, `build_vg_asset`) не меняются и не удаляются. DAG — новый вид ассета, включаемый явно.

## Суть
Сейчас LOD в VG — это 3 независимых уровня упрощённого меша (`LodChainConfig`, `asset_pipeline.rs:189`), выбираются на меш целиком (`select_lod`, `lod.rs:100`). Скачки LOD видны, и один дальний кусок большого меша детализируется так же, как ближний.
Нужна иерархия кластеров: ошибка и выбор по кластеру, без швов. Это самая сложная часть VG; поэтому она разложена на шаги, где каждый проверяется чистыми тестами **без GPU**.

## Что уже есть (проверено чтением)
- `meshopt` 0.6 в workspace (`Cargo.toml:76`), в `asset_pipeline.rs:25–27` импортированы `SimplifyOptions, VertexDataAdapter, build_meshlets, compute_meshlet_bounds, simplify, simplify_scale`; функции `position_adapter` (45), `simplify_level` (63), `cluster_level` (103), `build_vg_asset` (189).
- `MeshletDescriptor` (64 байта: вершины, индексы, сфера, конус, `lod_error`, `lod_level`, `material_index`), `VGAssetData { vertices, indices, meshlets, aabb }` (`meshlet.rs`), константы `MAX_VERTICES_PER_MESHLET = 64`, `MAX_TRIANGLES_PER_MESHLET = 124`.
- Кэш `.cache/vg/*.rmesh` (`cache.rs`, версия 1, `cache_key`).
- Бенчмарк `benches/meshlets.rs`.

## Идея (Nanite-подобная, упрощённая)
1. Уровень 0: кластеры из `build_meshlets` по исходному мешу.
2. Повторять, пока кластеров > 1: сгруппировать соседние кластеры по 4 (допустимо 2–6); для группы склеить треугольники; упростить вдвое с **замороженной внешней границей группы** (`SimplifyOptions::LockBorder` — граница склеенного подмеша = граница группы);
   нарезать результат на 2 кластера (`build_meshlets`); записать ошибку группы.
3. Условие отрисовки кластера: `error(cluster) в пикселях ≤ порог` **и** `error(parent) в пикселях > порог`. Для отсутствия швов у всех кластеров одной группы одинаковые `lod_sphere` и `parent_error`, а ошибка родителя ≥ ошибки детей.

## Типы (шаг 1)
Файл `virtual_geometry/dag.rs`:
```rust
/// One cluster of the hierarchy. Triangles live in the asset's index buffer at `index_offset..index_offset+index_count`.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct DagCluster {
    pub index_offset: u32,
    pub index_count: u32,
    /// Bounding sphere of this cluster's geometry (local space).
    pub center: [f32; 3],
    pub radius: f32,
    /// Sphere and error that decide when THIS cluster is precise enough. Shared by all clusters of one group.
    pub lod_center: [f32; 3],
    pub lod_radius: f32,
    pub error: f32,
    /// Sphere and error of the group that REPLACES this cluster; `f32::INFINITY` error for the root.
    pub parent_lod_center: [f32; 3],
    pub parent_lod_radius: f32,
    pub parent_error: f32,
    /// Level in the hierarchy (0 = full detail leaves).
    pub level: u32,
    /// Group this cluster was created by (u32::MAX for leaves).
    pub group: u32,
}

#[derive(Clone, Debug, Default)]
pub struct ClusterDag { pub clusters: Vec<DagCluster>, pub root_count: u32 }

/// Screen-space size in pixels of an object-space `error` measured on a sphere `(center, radius)` seen from `eye`
/// with the projection scale `pixels_per_unit_at_1m` (= screen_height / (2 * tan(fov_y/2))). The distance is taken to the nearest point of the sphere (>= near).
pub fn projected_error_px(error: f32, center: [f32; 3], radius: f32, eye: [f32; 3], pixels_per_unit_at_1m: f32) -> f32;

/// CPU reference of the cut: the clusters to draw for threshold `max_error_px`. A cluster is chosen when
/// projected(error) <= max_error_px && projected(parent_error) > max_error_px.
pub fn cut(dag: &ClusterDag, eye: [f32; 3], pixels_per_unit_at_1m: f32, max_error_px: f32) -> Vec<u32>;

/// Structural checks used by tests and by the cook: returns the list of violated rules (empty = ok).
pub fn validate(dag: &ClusterDag) -> Vec<String>;
```
`projected_error_px`: `d = max(|center - eye| - radius, 0.001)` (расстояние до ближайшей точки сферы, не ближе 1 мм); результат `error * pixels_per_unit_at_1m / d`. Это же формула, которую повторит шейдер VG-02.

Шаг 1, тесты (юнит, DAG строится вручную в тестах — 3 уровня: 4 листа → 2 → 1):
```rust

#[test] fn a_zero_distance_inside_the_sphere_does_not_divide_by_zero() { /* eye in the centre: finite and large */ }
#[test] fn the_root_is_always_chosen_when_everything_is_far() { /* huge distance: cut == [root] */ }
#[test] fn the_leaves_are_chosen_when_the_eye_is_close_with_a_small_threshold() { /* cut == all leaves */ }
#[test] fn the_cut_never_picks_a_cluster_and_its_ancestor_together() { /* sweep eye distance 0.1..1000 in 60 steps: no chosen id is an ancestor of another (ancestors via group links in the test DAG) */ }
#[test] fn the_cut_covers_every_leaf_exactly_once() { /* each leaf is under exactly one chosen cluster (descendants set) */ }
#[test] fn validate_reports_a_parent_error_lower_than_the_child_error() { /* broken DAG -> message */ }
#[test] fn validate_accepts_a_correct_dag() { /* [] */ }
```
`validate` проверяет: ошибка родителя ≥ ошибки ребёнка (для каждой пары по `group`), у всех кластеров группы одинаковые `lod_*`/`parent_*`, у корня `parent_error == INFINITY`, у листьев `error == 0.0` и `group == u32::MAX`, `parent_lod_radius >= lod_radius`, `parent_lod` сфера содержит `lod` сферу (расстояние центров + radius_child ≤ radius_parent + 1e-4).

## Шаг 2 — группировка соседних кластеров (S, без meshopt)
```rust
/// Partitions clusters into groups of `target` (2..=6) by shared edges. `shared_edges[i]` lists `(j, count)` neighbours of cluster i. Deterministic.
pub fn group_clusters(cluster_count: usize, shared_edges: &[Vec<(u32, u32)>], target: usize) -> Vec<Vec<u32>>;
/// Counts, for each cluster pair, the boundary edges they share. Input: per cluster a list of undirected edges (pairs of position-welded vertex ids).
pub fn adjacency(cluster_edges: &[Vec<(u32, u32)>]) -> Vec<Vec<(u32, u32)>>;
```
Алгоритм группировки (жадный, детерминированный): пока есть неотнесённые, взять кластер с наименьшим индексом; добавлять соседа с наибольшим `count` общих рёбер (при равенстве — меньший индекс), пока в группе `target`; если соседей нет — группа остаётся меньше.
Последняя неполная группа из 1 кластера присоединяется к соседней группе, если та не превышает 6; иначе остаётся одиночной (одиночный кластер всё равно упрощается).
Тесты: `every_cluster_is_in_exactly_one_group`; `groups_never_exceed_the_maximum`; `neighbours_with_most_shared_edges_are_grouped_first` (сетка 4×4 кластеров: первая группа — компактный блок, а не «через одного»); `an_isolated_cluster_forms_its_own_group`; `grouping_is_deterministic` (дважды — одинаково); `adjacency_counts_shared_edges_symmetrically`.

## Шаг 3 — построение DAG (M, `meshopt`)
```rust
pub struct DagParams { pub group_size: usize /* 4 */, pub target_ratio: f32 /* 0.5 */, pub max_levels: u32 /* 24 */ }
/// Builds the hierarchy for a mesh. Positions are welded internally by position (same position = same vertex for adjacency and simplification);
/// the returned `indices` are indices into the ORIGINAL vertex array of the mesh, so attributes stay intact.
pub fn build_cluster_dag(vertices: &[Vertex], indices: &[u32], params: &DagParams) -> Result<(ClusterDag, Vec<u32>), DagError>;
```
Тело:
1. Сварка по позиции (хеш по битам `[f32;3]`, ноль и −0 приводить к одному) → `welded: Vec<u32>` (индекс вершины → канонический).
2. Уровень 0: `build_meshlets(…, 64, 124, cone_weight 0.0)` → `DagCluster` с `error = 0.0`, `level = 0`, `group = u32::MAX`.
3. Цикл по уровням: `adjacency` (рёбра берутся по сваренным индексам), `group_clusters`, для каждой группы: склеить индексы, `simplify(…, target_count = склеенное_число_индексов * ratio, SimplifyOptions::LockBorder, &mut err)`; **ошибка группы** `e = err * simplify_scale(&adapter)` (в единицах объекта, как в `simplify_level`, `asset_pipeline.rs:94`);
   `group_error = max(e, max(error детей)) * 1.0 + ulp` — строго не меньше ошибок детей (`next_up`-подобный запас: `max(e, child_max) + child_max * 1e-3 + 1e-6`);
   `group_sphere` = минимальная охватывающая детей `lod`-сфера (простая: центр — среднее центров, радиус — максимум `|c_i - c| + r_i`); нарезать результат на кластеры (по `ratio` ожидаем ≈ 2 кластера на 4 исходных);
   детям записать `parent_*` = `group_sphere`/`group_error`; новым кластерам — `error = group_error`, `lod_* = group_sphere`, `group = id группы`.
4. Остановка: один кластер на уровне, либо `max_levels`, либо группа не упростилась (результат ≥ 90% исходных треугольников — «застряла»: оставить группу как корневую, `parent_error = INFINITY` у всех кластеров верхнего уровня; `root_count` = их число, **ошибкой это не считается**).
5. `validate(&dag)` в конце: непустой результат → `DagError::Invalid(Vec<String>)`.
Детерминизм: порядок групп и кластеров не зависит от хеш-порядка (сортировать по индексам); `meshopt` детерминирован при одинаковых входах.
Тесты (`virtual_geometry/dag.rs` + `tests/vg_dag.rs`; меши — `uv_sphere`, `cube_mesh` как в `asset_pipeline.rs:269–360`, вынести в общий тестовый модуль или продублировать):
```rust
#[test] fn a_sphere_builds_a_valid_hierarchy() { /* uv_sphere(1, 48, 96): validate == [], root_count == 1 или малое число, число уровней >= 3 */ }
#[test] fn the_root_has_few_triangles() { /* корневые кластеры суммарно <= 2 * 124 треугольников */ }
#[test] fn leaves_reproduce_the_original_triangles() { /* сумма треугольников листьев == исходному, ни один не потерян и не дублирован (мультимножество граней по сваренным вершинам) */ }
#[test] fn parent_errors_never_decrease_up_the_hierarchy() { /* validate */ }
#[test] fn the_build_is_deterministic() { /* дважды: равные ClusterDag и индексы */ }
#[test] fn an_empty_or_degenerate_mesh_is_an_error() { /* пустой -> Err(Empty) */ }
#[test] fn a_mesh_that_fits_in_one_cluster_is_just_the_root() { /* куб: 1 кластер, parent_error == INFINITY, error 0 */ }
#[test] fn welded_seams_do_not_open_cracks() { /* сфера с разорванным UV-швом (дублированные вершины по меридиану) — после сварки открытых рёбер = 0 на любом срезе, см. шаг 4 */ }
```

## Шаг 4 — проверка отсутствия трещин (M, чистые тесты — главная гарантия)
Чистая функция в `dag.rs`: `pub fn open_edge_count(clusters_indices: impl Iterator<Item = (u32,u32,u32)>, weld: &[u32]) -> usize` — число неориентированных рёбер, встречающихся ровно один раз (по сваренным вершинам).
Тесты `tests/vg_dag.rs`:
```rust
#[test] fn a_closed_mesh_has_no_open_edges_at_any_cut() {
    // сфера (замкнутая): для 40 значений расстояния камеры (0.5 .. 200) и порогов {0.5, 1, 2, 4} px:
    // cut -> треугольники выбранных кластеров -> open_edge_count == 0
}
#[test] fn an_open_mesh_keeps_exactly_its_own_border_at_any_cut() {
    // плоская сетка 40x40 (открытая): число открытых рёбер на любом срезе == числу рёбер периметра исходной сетки (160) ... допускается <= (периметр исходной сетки), и ни одной новой «дыры» внутри (проверить: все открытые рёбра лежат на AABB-границе сетки)
}
#[test] fn cuts_of_neighbouring_thresholds_differ_only_by_whole_groups() { /* два среза с порогами 1.0 и 1.1: симметрическая разность выбранных кластеров состоит из полных групп (все кластеры группы либо в одном, либо в другом) */ }
#[test] fn the_triangle_count_drops_as_the_eye_moves_away() { /* число треугольников среза не растёт с расстоянием (монотонно по 30 точкам) */ }
```

Если любой из первых двух тестов красный — это ошибка граней/ошибок, **не править тест**, а остановиться и отчитаться координатору (признак, что `LockBorder` не заморозил общую границу из-за несваренных вершин).

## Шаг 5 — формат ассета, кэш, включение (S)
- `VGDagAsset { vertices: Vec<Vertex>, indices: Vec<u32>, dag: ClusterDag, aabb, material_index }` (серилизуемый, `Vec<DagCluster>` — `Pod`: проверить, что `DagCluster` подходит под `bytemuck::Pod` (поля `f32/u32`, без паддинга; при необходимости добавить явные `_pad`), размер кратен 16).
- `cache.rs`: версия 2 для DAG-кэша, отдельное расширение `.rdag` (старый `.rmesh` не трогать); ключ — `cache_key` + `DagParams`.
- `redox_cook`: флаг/команда **не обязательны** на этом шаге; ассет строится библиотечной функцией `build_vg_dag_asset(mesh, params)`; интеграция с `VGSystem` — VG-02.
- Тесты: `dag_asset_roundtrips_through_the_cache` (запись/чтение — равно); `a_cache_of_another_version_is_ignored_not_fatal`; `bytemuck_layout_of_DagCluster_is_16_byte_aligned` (`size_of % 16 == 0`).

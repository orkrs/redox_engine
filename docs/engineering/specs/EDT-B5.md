# EDT-B5 — Редактор, этап B, срез B5: редактор материалов (`.matgraph`)

- **Статус:** не начат.
- **Размер:** 6 шагов (M, M, M, M, M, S) ≈ 8 дней. **Крейты:** `redox_matgraph`, `redox_editor_ui`, `redox_editor_assets`, `redox_editor_core`, `redox_render` (preview), `redox_editor`. **Зависит от:** MAT-02/MAT-08 (компиляция графа), A3 (Undo), желательно B3 (preview lighting). **Блокирует:** ТЗ §23.7; часть B7 (материал с ошибкой).
- **Исполнение:** агент без cargo; GPU preview-тесты — координатор.
- Источник: `EDITOR_PLAN.md` §6 B5; ТЗ §7.3. **Правило ТЗ:** материал, который не собирается для игры, **сохранить нельзя**.
- **Не входит:** полный shader text editor (отдельный D), VFX graph.

## Суть
`redox_matgraph` умеет граф → IR → WGSL; в UI есть `NodeCanvas` с демо-графами, но нет открытия `.matgraph`, компиляции из редактора, ошибок с прыжком к узлу и превью на сфере. Срез делает authoring материалов внутри Studio.

## Что уже есть
- `redox_matgraph`: graph, check, IR, emit WGSL, hot reload cache в render.
- `redox_editor_ui/src/node_canvas.rs`: холст узлов (демо StateTree/AnimGraph/PCG).
- Asset browser kind detection по расширению.

## Шаг 1 — документ материала и I/O (M)
- `MaterialDocument` в editor (без egui): open/save `.matgraph` (RON), dirty, format_version, migrate.
- Привязка к GUID ассета; Save только после успешной `matgraph` typecheck+emit (правило ТЗ); иначе ошибка и файл не пишется.
- Тесты: roundtrip; граф с ошибкой типов → `save` Err, файл на диске не изменился; корректный граф → байты обновлены.

## Шаг 2 — модель графа для UI (M)
- Адаптер `MatGraphView` поверх `redox_matgraph` с типами пинов, соединениями, валидацией ребра.
- Undo: транзакции на add/remove node, connect, set param (снимки графа или командный diff — выбрать проще: snapshot графа на commit).
- Тесты: connect несовместимых пинов отклоняется; Undo возвращает граф.

## Шаг 3 — NodeCanvas для материалов (M)
- Режим/вкладка Material Editor на `NodeCanvas`: загрузка документа, сериализация жестов в модель шага 2.
- Список ошибок компиляции; клик → focus node id.
- Тесты модели ошибок (без egui): error carries node id.

## Шаг 4 — превью (M)
- Preview target: sphere / cube / plane; выбор освещения (IBL если B3, иначе простой light).
- GPU-тест цвета на известном графе (как `mat03_tex_gpu`): ожидаемый цвет в допуске.
- Hot reload: изменение графа → пересборка варианта (использовать существующий cache).

## Шаг 5 — параметры и инстансы (M)
- Панель параметров материала и per-instance overrides (если тип уже есть в движке; иначе только asset-level 📌).
- Показ сгенерированного WGSL (read-only).
- Тесты: param change → dirty → save ok.

## Шаг 6 — интеграция (S)
- Open from Asset Browser double-click `.matgraph`; вкладка документа.
- Команды палитры; сценарий §23.7.
- Отчёт, CHANGELOG, KNOWN_LIMITS.

## Границы
- **Читать:** `redox_matgraph/**`, `node_canvas.rs`, MAT-08 report.
- **Создать:** material document, view model, preview hook, tests.
- **Менять:** node_canvas, asset browser open path, dock tabs.
- **Не трогать:** OFPA, PIE.

# RFL-03 — `bake-probes`: офлайн-кубы проб и загрузка вместо захвата

- **Статус:** не начат (аудит кода 2026-11-15). Владелец разрешил писать шаг, который RFL-01 отложил.
- **Размер:** 4 шага (S, M, M, S) ≈ 6 дней. **Крейты:** `redox_cook`, `redox_render`, `redox_core`. **Зависит от:** RFL-01 (`export_ktx2`, захват, слоты), RFL-02 (пробы в мире и слоты кадра). **Блокирует:** —.
- **Модель:** haiku. Сравнение захвата и файла — с проверкой координатора на GPU.
- Команда cook пишет кубы, уровень поднимает их без шести граней в рантайме. **Не входит:** перевод захвата в HDR (ограничение RFL-01), больше четырёх проб, пробы каждый кадр.

## Суть
RFL-01 шаг 5 не писался: «не писать, если шаги 1–4 заняли больше 7 дней». Захват в рантайме есть, `IBLProcessor::export_ktx2` пишет набор. `ReflectionProbeSet::load_baked` нет, команды `redox_cook bake-probes` нет. Каждый запуск уровня, который хочет локальные отражения, переснимает грани.

## Что уже есть
- Захват слота и prefiltered-куб в массиве проб.
- Загрузка KTX2 для обычного IBL (`read_texture_ktx2` / `from_ktx2` — **ПРОВЕРИТЬ** актуальное имя и использовать его).
- Допуск приёмки из RFL-01: запечённая проба совпадает с захватом в ±2/255.

## Шаг 1 — файл одной пробы (S)
- Имя `<probe_id>.ktx2` (prefiltered, те же мипы и формат, что у захвата). Рядом `probes.ron`: id, центр, half extent, blend, priority.
- `write_probe` / `read_probe` на байтах. Чужой заголовок и обрез — ошибка.
Тесты: `a_probe_file_roundtrips_the_box_metadata`; `a_truncated_ktx2_is_an_error`.

## Шаг 2 — `redox_cook bake-probes` (M)
- `redox_cook bake-probes <world> <out-dir>`: расставить пробы так же, как RFL-02 читает их из мира, для каждой снять кадр **тем же** `capture_reflection_probe` (не второй рендерер) и записать KTX2. Фича `bake`, как у `bake-ibl`, если захват требует GPU-рендерера.
- Повторный запуск с тем же миром даёт те же байты метаданных. Байты куба детерминированы настолько, насколько детерминирован захват; если нет — в отчёте хеш и причина, метаданные всё равно детерминированы.
Тест GPU: `bake_probes_writes_one_file_per_probe`. Без адаптера команда завершается понятной ошибкой, не паникой (как `bake-ibl`).

## Шаг 3 — `load_baked` (M)
- `ReflectionProbeSet::load_baked` заполняет слоты из файлов и не ставит грязный флаг захвата.
- RFL-02: если у пробы лежит файл новее сцены, слот берётся из файла. Файла нет — слот грязный, работает захват RFL-02.
Тест GPU: `a_baked_probe_matches_the_runtime_capture` (макс. отклонение канала ≤ 2/255 на мипе 0 в направлении стены). `loading_baked_probes_does_not_run_capture` (счётчик захватов кадра равен 0).

## Шаг 4 — cook-отчёт и документация (S)
- Профиль cook вызывает bake, когда в мире есть пробы, и пишет `probes: "written" | "skipped"` в `cook_report.json`.
- `docs/ASSETS.md`, `CHANGELOG.md`. В RFL-01 одной строкой: шаг 5 выполняется как RFL-03.

## Границы
- **Читать:** RFL-01, RFL-02, `redox_cook/src/bake.rs`, `reflection/capture.rs`.
- **Менять:** `redox_cook/src/main.rs` (одна команда), набор проб в рендерере, плагин RFL-02.
- **Не трогать:** параллакс, число слотов, пост-цепочку граней.

## Проверка
`cargo fmt`, `cargo clippy -p redox_cook -p redox_render -p redox_core --all-targets -- -D warnings`, `cargo test -p redox_render --test reflection_probes`, команда bake на фикстуре с одной пробой.

Если RFL-02 ещё не влит — шаг 3 сначала грузит файлы по явному вызову `load_baked`, а подстановка «файл новее сцены» помечается 📌 до появления грязного флага.

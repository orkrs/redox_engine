# VG-05 — HLOD при старте игры и в PIE

- **Статус:** не начат (аудит кода 2026-11-15).
- **Размер:** 3 шага (S, M, S) ≈ 4 дня. **Крейты:** `redox_core`, `redox_editor`. **Зависит от:** VG-04 (`bake-hlod`, `HlodPlugin`, `load_hlod_scene`). **Блокирует:** —.
- **Модель:** haiku.
- Закрывает заметку `BENCHMARKS.md`: загрузка `.hlod` при старте не подключена. **Не входит:** цвет вершины прокси на GPU (ограничение VG-04), импосторы, смена формата `.hlod`.

## Суть
`HlodPlugin` в `redox_core/src/hlod_load.rs` на `on_render_setup` читает `world.bin`, соседние `.hlod` и `actor_kinds.ron`, кладёт рантайм в мир и вешает `hlod_frame_system` на `Stage::Render`. Вызовов `add_plugin(HlodPlugin { .. })` в репозитории нет. Без них запечённые прокси лежат на диске.

## Что уже есть
- Плагин ничего не меняет, если `.hlod` или `actor_kinds.ron` отсутствуют (`Ok(None)`).
- Кадровый шаг выключен без прокси и без `HlodSettings.enabled`.
- Команда `redox_cook bake-hlod` уже пишет файлы.

## Шаг 1 — точка включения (S)
- Функция `hlod_plugin_for(world_bin: &Path) -> Option<HlodPlugin>`: плагин собирается, только если рядом есть хотя бы один `.hlod` и `actor_kinds.ron`. Иначе `None`.
- `App::with_hlod(self, world_bin: PathBuf) -> Self` добавляет плагин, когда `hlod_plugin_for` вернул `Some`.
Тесты: `no_hlod_files_means_no_plugin`; `a_folder_with_a_proxy_builds_the_plugin`; `plugin_without_files_does_not_change_the_frame` (уже обещано VG-04 — повторить на пути `with_hlod`).

## Шаг 2 — игра и PIE (M)
- Старт игры, которая открывает `world.bin`, вызывает `with_hlod` этим путём.
- PIE редактора делает то же для открытого мира. Обычный viewport редактора прокси не подменяет (далеко от камеры редактора HLOD не обязателен): в PIE — да.
- Порядок систем: `HlodPlugin` регистрируется до системы, которая забирает объекты на отрисовку (комментарий в `hlod_load.rs` про порядок в стадии).
Тест: `pie_boot_inserts_hlod_runtime_when_proxies_exist` (мир-фикстура из теста `hlod_load`, после setup в мире есть рантайм). `pie_boot_without_proxies_has_no_runtime`.

## Шаг 3 — cook не забывает прокси (S)
- Если профиль cook уже умеет вызвать `bake-hlod` для мира — оставить. Если нет — шаг cook рядом с NAV-06: при наличии `world.bin` написать `.hlod` в `.redox` и отразить это в `cook_report.json` (`hlod: "written" | "skipped"`). Общий хелпер с CLI, второй реализатор упрощения не писать.
Тест: `cook_writes_hlod_or_skips_when_there_is_no_world`.

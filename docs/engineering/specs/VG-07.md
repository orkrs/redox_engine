# VG-07 — DAG-мешлеты в кадре игры и редактора

- **Статус:** не начат (аудит кода 2026-11-15).
- **Размер:** 3 шага (S, M, S) ≈ 4 дня. **Крейты:** `redox_render`, `redox_editor`. **Зависит от:** VG-02 (обход DAG), VG-06 (ассет зарегистрирован). **Блокирует:** —.
- **Модель:** haiku.
- Обход DAG уже вызывается из кадра. Спека включает его на тех ассетах, которые являются DAG, и доводит инстансы до игры и viewport. **Не входит:** новый обход, смена порога ошибки в пикселях, страничный резидентный набор VG-03.

## Суть
`Renderer` в `crates/redox_render/src/renderer/frame/vg.rs` вызывает `record_dag_traverse`, когда `vg.config.dag_traverse` и `dag_instance_count() > 0`. Значение по умолчанию в `virtual_geometry/runtime/types.rs` — `dag_traverse: false`. Инстансов DAG в редакторе и в игровом старте нет, поэтому ветка не выполняется. Запись CHANGELOG «рендерер не вызывает DAG» устарела: вызов есть, данных нет.

## Что уже есть
- Тест `tests/vg_dag_frame.rs` включает флаг и регистрирует ассет.
- CPU-`cut` остаётся эталоном выбора кластеров (VG-02).

## Шаг 1 — флаг следует из ассета (S)
- Ассет с иерархией кластеров регистрируется с `dag_traverse: true`. Плоский мешлет-ассет без DAG этот флаг не включает.
- Глобально «включить всем» нельзя: плоский путь GPU-cull остаётся для ассетов без дерева.
Тест: `a_dag_asset_enables_traversal`; `a_flat_meshlet_asset_leaves_traversal_off`.

## Шаг 2 — инстанс в сцене (M)
- Игра и viewport, получив DAG-ассет из VG-06, вызывают существующий spawn инстанса (имя — как в `vg_dag_frame.rs`, **ПРОВЕРИТЬ** и не заводить параллельный список).
- Кадр с одним DAG-инстансом в кадре камеры даёт ненулевой `dag_instance_count` и проходит `record_dag_traverse` без ошибки устройства.
Тест GPU: `a_spawned_dag_instance_is_drawn` (сравнение с CPU-cut: видимые кластеры совпадают на статичной камере в допуске VG-02). `no_dag_instance_skips_the_pass` (плоская сцена не трогает DAG-буферы).

## Шаг 3 — документация (S)
Поправить CHANGELOG и `PLAN_GEOMETRY.md` / `PLAN_EXECUTION.md`: обход вызывается из `frame/vg.rs`, по умолчанию выключен только у ассетов без дерева. `CHANGELOG.md` новой записи достаточно, старую историческую строку не переписывать задним числом — добавить уточнение сверху.

## Границы
- **Читать:** VG-02, `frame/vg.rs`, `runtime/types.rs`, `runtime/dag.rs`, `tests/vg_dag_frame.rs`.
- **Менять:** место регистрации ассета и спавна инстанса.
- **Не трогать:** шейдер `vg_dag_traverse.wgsl`, порог ошибки.

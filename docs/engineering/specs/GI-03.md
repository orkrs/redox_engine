# GI-03 — G3: экранные пробы и финальный сбор (резкий локальный GI)

- **Статус:** не начат. **Ворота:** шаги 2–5 только если замер GI-01/GI-02 показал, что одних мировых проб не хватает по резкости (контактный непрямой свет, тонкие детали).

- **Размер:** 5 шагов (S, M, M, M, S) ≈ 14 дней. **Крейт:** `redox_render`. **Зависит от:** GI-01, GI-02 (атлас излучения карточек, глобальный SDF). **Блокирует:** —.
- **Модель:** haiku по шагам 1, 5; шаги 2–4 (шейдеры трассировки, фильтра, сбора) — haiku с проверкой координатора после каждого шага.
- Цель плана: пробы по тайлам 16×16, трассировка по Hi-Z для контактных деталей, фильтрация во времени и пространстве. **Не входит:** адаптивная плотность проб (одна проба на тайл), аппаратные лучи, зеркальные отражения (GI-04).

## Суть
Мировые пробы GI-01 дают мягкий свет с шагом сетки 1–4 м: углы, щели и предметы на полу «плавают» над светом. Экранные пробы кладутся на **видимые** поверхности: по одной на тайл 16×16 пикселей (1080p = 120×68 ≈ 8160 проб); каждая бросает 64 луча (октаэдр 8×8), трассирует их сначала по глубине экрана, затем по глобальному SDF/карточкам, и хранит радиацию. Каждый пиксель интерполирует освещённость из 4 ближайших экранных проб с весами по глубине и нормали.
Результат — `t_gi_screen` (диффузный непрямой свет), который основной шейдер умножает на альбедо вместо выборки мировых проб (мировые остаются запасным вариантом для пикселей без хорошей экранной пробы и для уровней качества Low/Medium).

## Что уже есть (проверено чтением)
- Проход нормалей/глубины до основного (`pass/normal.rs`, `shaders/normal.wgsl`): нормаль мира (xyz) + глубина вида `/ NORMAL_DEPTH_RANGE` (w) и второй вывод — roughness/metallic (`Rg8Unorm`). Используется GTAO и SSR.
- Скорость (`pass/velocity.rs`, `object_velocity.wgsl`) и история TAA (`pass/taa.rs`) — для репроекции.
- Hi-Z есть только в VG (`virtual_geometry/hiz.rs`, `hiz_copy.wgsl`, `hiz_downsample.wgsl`) — для сцены вне VG пирамиды глубины **нет**; SSR (`ssr.wgsl`) идёт линейным шагом без пирамиды. Шаг 2 строит собственную пирамиду глубины (переиспользовать шейдеры `hiz_*` — **ПРОВЕРИТЬ** их привязки).
- Трассировка по SDF и карточкам — GI-01/GI-02 (`gi_trace.wgsl`, `gi_common.wgsl`).

## Шаг 1 — чистая математика и эталон (S, без GPU)
`src/gi/screen_probes.rs`:
```rust
pub const TILE: u32 = 16;
/// Probe grid size for a render target.
pub fn probe_grid(width: u32, height: u32) -> (u32, u32);              // ceil(w/16), ceil(h/16)
/// Pixel position of the probe inside tile (tx,ty): the pixel whose depth is closest to the tile mean, ties -> lowest index; jittered by `frame` among the 4 central pixels when `jitter` is true.
pub fn choose_probe_pixel(tile_depths: &[f32; 256], frame: u32, jitter: bool) -> (u32, u32);
/// Weight of probe `p` for pixel `x`: bilinear * depth_weight * normal_weight.
pub fn interpolation_weight(bilinear: f32, plane_distance: f32, depth_sigma: f32, n_pixel: Vec3, n_probe: Vec3) -> f32;
/// Cosine-weighted irradiance from 8×8 octahedral radiance (`radiance[8*8]`) for normal `n`.
pub fn irradiance_from_oct(radiance: &[Vec3; 64], n: Vec3) -> Vec3;
```
Реализация: `plane_distance` = расстояние пикселя до плоскости пробы (`|dot(n_probe, p_pixel − p_probe)|`) в метрах; `depth_weight = exp(-(plane_distance/depth_sigma)²)`; `normal_weight = max(dot(n_pixel, n_probe), 0)^8`; `irradiance_from_oct` суммирует `radiance[i] * max(dot(oct_dir(i), n), 0) * solid_angle(i)` и нормирует так, чтобы константа `L` давала `π·L`.
Тесты:
```rust

#[test] fn a_flat_tile_picks_the_first_pixel_without_jitter() { /* ... */ }
#[test] fn jitter_stays_inside_the_central_four_pixels() { /* ... */ }
#[test] fn a_probe_behind_an_edge_gets_a_tiny_weight() { /* plane_distance 1 м при sigma 0.1 -> < 1e-3 */ }
#[test] fn opposite_normals_get_zero_weight() { /* ... */ }

```

## Шаг 2 — размещение и трассировка (M)
- Пирамида глубины сцены: `post/depth_pyramid.rs` (R32Float, мипы до 1×1, `max` по 2×2 — для «дальнего» Hi-Z; переиспользовать `hiz_downsample.wgsl` или написать свой **ПРОВЕРИТЬ** совместимость формата); строится после нормального префасса, пересоздаётся в `resize.rs`.
- `shaders/gi_screen_place.wgsl`: по тайлам выбрать пиксель пробы (зеркало `choose_probe_pixel`), записать в `probe_pos_normal: array<vec4>` (мировая позиция + глубина, нормаль) ; тайлы без геометрии (небо) — `valid = 0`.
- `shaders/gi_screen_trace.wgsl` (`workgroup_size(64)` на пробу × 64 луча = 4096 потоков на 64 пробы…): луч из точки пробы со смещением по нормали, **сначала** линейный/Hi-Z шаг по глубине экрана (максимум 24 шага, ограничение по дальности 2 м), при попадании — цвет предыдущего кадра HDR `t_prev_color` (после тонмаппинга не годится: использовать HDR-цель до пост-цепочки, **ПРОВЕРИТЬ** `renderer/attachments.rs`), иначе дальнейший путь по глобальному SDF (код из `gi_trace.wgsl`, вынесенный в общую функцию `trace_world(origin, dir) -> vec4`) с карточками; промах → небо. Результат — `radiance: array<vec4>` по `probe*64+ray`.
- Выход: `screen_radiance` текстура `Rgba16Float` размером `(probes_x*8, probes_y*8)` (каждая проба — плитка 8×8 октаэдра).
Тесты (GPU, `tests/gi_screen.rs`):

## Шаг 3 — фильтрация (M)
- Время: `screen_radiance_history` (ping-pong); репроекция пробы по скорости пикселя пробы (`velocity` текстура), принимать историю, если `|depth − depth_hist| < 0.05·depth` и `dot(n, n_hist) > 0.9`; `hysteresis = 0.9` (при отклонении 0,5). Хранить число накопленных кадров.
- Пространство: 3×3 фильтр между соседними пробами (веса `interpolation_weight` шага 1), только для проб с `frames < 8`.
- Ограничение «светляков»: `radiance = min(radiance, luminance_cap)`, `cap = 8×` среднего по плитке.

## Шаг 4 — финальный сбор и включение (M)
- `shaders/gi_screen_gather.wgsl` (полноэкранный compute, 8×8): для каждого пикселя — 4 ближайшие пробы (по сетке 16×16 + сдвиг на половину тайла), веса `interpolation_weight`, `irradiance_from_oct`; результат `t_gi_screen: Rgba16Float` (при половинном разрешении — билатеральный апсемпл по глубине: настройка `GiScreenSettings::half_res`, по умолчанию true).
- `pbr.wgsl`: привязка `t_gi_screen` + флаг `gi_screen_enabled` в `GiGridGpu`; если включено и вес сбора > 0,2 → `gi = t_gi_screen`, иначе мировые пробы (GI-01). Добавляется **одна** текстура (лимит поднят RFL-01).
- `GiQuality::High` включает экранные пробы; `Medium` и ниже — нет (кадр побитно как у GI-01).
- Кадровый граф: проходы `gi_screen_place → gi_screen_trace → gi_screen_filter → gi_screen_gather` после нормального префасса и до основного.
Тесты (GPU, `tests/gi_screen_scene.rs`):

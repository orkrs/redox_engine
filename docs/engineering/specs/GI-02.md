# GI-02 — G2: поверхностный кэш (карточки: цвет и освещённость поверхностей в точке попадания луча)

- **Статус:** шаги 1–5 написаны (код и тесты; в агенте только `cargo check --all-targets`, тесты не запускались; замер и приёмка — координатор). Отступления: эмиссия карточки скалярная (белый цвет); точечные огни на карточках без теней; текстура при захвате — `base_color`; тесты трассировки «задняя стена» и «многократный отскок» не написаны (см. отчёт).

- **Размер:** 5 шагов (S, M, M, M, S) ≈ 14 дней. **Крейт:** `redox_render`. **Зависит от:** GI-01 (глобальный SDF, трассировка и атлас проб). **Блокирует:** GI-04.
- **Модель:** haiku по шагам 1, 2, 5; шаги 3–4 (шейдеры освещения карточек и считывание в трассировке) — haiku с проверкой координатора.
- Цель плана: цвет и свет в точках попадания правильные, многократные отражения. **Не входит:** динамические и скинированные объекты (карточки только у статики), карточки по сложным мешам (только 6 осевых на объект), текстуры при захвате (берётся средний цвет текстуры × `base_color`).

## Суть
В GI-01 попадание луча даёт `albedo` из объёма 128³ (цвет ближайшего кирпича), а освещённость берётся из прошлого кадра проб. Это грубо: цвет — одна константа на кирпич, нет точечных ламп, нет света окон/эмиссии с текстур.
Карточка = ортографический снимок объекта вдоль одной из 6 осей (±X, ±Y, ±Z): альбедо, нормаль, эмиссия, глубина. Карточки лежат в атласе; каждый кадр часть тексов **освещается** (солнце, точечные огни, непрямой свет из проб GI-01) в атлас излучения `card_radiance`. Луч, попавший в объект, считывает `card_radiance` по проекции точки попадания.
Решение «оптимально»: **карточки снимаются на CPU программным растеризатором** (меши статики лежат в памяти как `Mesh`, захват делается один раз при загрузке: детерминированно, тестируется без GPU); освещение — compute на GPU; **6 осевых карточек на объект**.

## Что уже есть (проверено чтением)
- `Mesh` (`mesh/mod.rs`: вершины `Vertex { position, normal, uv, tangent }`, индексы), `Material { base_color, texture_index, emissive, … }` (`material.rs`), `RenderObject { id, shadow_class, model_matrix, color, mesh_index, material_index, bounds }` (`systems.rs`).

## Шаг 1 — раскладка карточек и атлас (S, без GPU)
- `src/gi/cards.rs`:
```rust
pub const CARD_FACES: usize = 6;
/// Orthographic face of an object's AABB, looking from outside inward.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum CardFace { PosX, NegX, PosY, NegY, PosZ, NegZ }
impl CardFace {
    pub fn normal(self) -> Vec3;
    /// (u axis, v axis, depth axis) as 0/1/2 indices; u,v span the card, depth runs from the face inward.
    pub fn axes(self) -> (usize, usize, usize);
}
/// Rectangle in the atlas (texels).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct AtlasRect { pub x: u32, pub y: u32, pub w: u32, pub h: u32 }
/// Texel size for a card: `ceil(extent / texel_world)` clamped to `[CARD_MIN, CARD_MAX]` (8..=128), multiples of 4.
pub fn card_size(extent_u: f32, extent_v: f32, texel_world: f32) -> (u32, u32);
/// Shelf packer for the atlas (2048², row height = tallest item in the row).
pub struct ShelfPacker { /* width, height, shelves */ }
impl ShelfPacker { pub fn new(w: u32, h: u32) -> Self; pub fn alloc(&mut self, w: u32, h: u32) -> Option<AtlasRect>; pub fn used_fraction(&self) -> f32; }
/// Projects a world point onto a card of an object with AABB `[min,max]`: `(uv in 0..1, depth in 0..1)`.
pub fn project_to_card(face: CardFace, aabb_min: Vec3, aabb_max: Vec3, p: Vec3) -> (Vec2, f32);
/// Blend weights of the six faces for a surface normal: `max(n·face_normal, 0)^2` normalised to sum 1 (zero vector -> equal weights).
pub fn face_weights(n: Vec3) -> [f32; CARD_FACES];
```

## Шаг 2 — захват карточки на CPU (M)
- `src/gi/card_capture.rs`: `capture_object(mesh: &Mesh, model: &Mat4, material: &CardMaterial, texel_world: f32) -> ObjectCards`, где
  `CardMaterial { albedo: Vec3 /* base_color × среднее цвета текстуры */, emissive: Vec3 }` (среднее цвета текстуры считает вызывающий: `Texture` может быть недоступна на CPU — тогда `base_color`),
  `ObjectCards { aabb_min, aabb_max, faces: [CardImage; 6] }`, `CardImage { w, h, albedo: Vec<[u8;4]> /*a = эмиссия/16*/, normal: Vec<[u8;4]> /*xyz в [0,255], a = глубина 0..255*/ }`.
- Алгоритм: вершины в мировом пространстве; ортографическая проекция по оси грани; растеризация треугольников барицентрическими координатами, z-буфер, перекрытие по центру пикселя; перед отрисовкой отбрасывать задние треугольники (нормаль грани против нормали треугольника ≥ 0 не нужна — глубина решает), цвет — `albedo`, нормаль — интерполированная нормаль вершин в мировых осях; пустые тексели: `a=0` у глубины (255 = «пусто»).
- Расширение краёв (dilation) на 2 текселя для билинейной выборки без швов.
Тесты:

## Шаг 3 — атлас на GPU и освещение карточек (M)
- `src/gi/card_atlas.rs`: `CardAtlas { albedo: Texture (Rgba8Unorm, 2048²), normal_depth: Texture (Rgba8Unorm), radiance: Texture (Rgba16Float, storage+sampled), table: storage buffer<CardObjectGpu>, objects: Vec<…> }`.
  `CardObjectGpu` (кратна 16): `aabb_min: vec4`, `aabb_max: vec4` (w = индекс объекта), `rects: [vec4<u32>; 6]` (x, y, w, h). Тест размера.
  `Renderer::set_gi_cards(&mut self, objects: &[(ObjectCards, u32 /*id*/)])` — упаковка в атлас (`ShelfPacker`), загрузка `queue.write_texture`, учёт памяти (категория текстур, «gi_cards»: 2048²×(4+4+8) = 64 МБ; **если больше лимита** `MemoryBudget` — снизить атлас до 1024² и отчитаться).
- `shaders/gi_card_light.wgsl` (compute 8×8): на каждый кадр обновляется `1/4` атласа (по кругу: кадр % 4 → полосы по строкам). Для тексела с `depth != 255`: восстановить мировую точку и нормаль (по таблице и обратной проекции), затем
  `radiance = emissive + albedo/π * (sun_visible * sun_rad * max(n·l,0) + Σ_{≤8 ближайших точечных} point_contrib + irradiance_probes(p, n))`,
  где видимость солнца и огней — **сферический шаг по глобальному SDF** (shadow ray, `eps = voxel`, 32 шага), точечные огни — первые 8 по расстоянию из `LightUniform` (**ПРОВЕРИТЬ** структуру в `light.rs`), `irradiance_probes` — функция выборки GI-01 (вынести в `shaders/gi_common.wgsl`, подключается как остальные общие куски — **ПРОВЕРИТЬ** `src/shader/mod.rs`).

## Шаг 4 — считывание карточек в трассировке (M)
- В `GlobalSdf` (GI-01) добавить объём `object_id: R16Uint` (id объекта-ближайшего, `0xFFFF` = нет): `from_boxes` и `from_bricks` принимают индекс; CPU-тест `the_object_id_volume_matches_the_nearest_object`.
- `gi_trace.wgsl`: в точке попадания вместо `albedo + bounce` — `card_radiance(hit_pos, hit_normal, object_id)`: для 3 лучших граней по `face_weights`: `(uv, depth) = project_to_card(…)`, считать `normal_depth` (билинейно через `textureSampleLevel`), принять карточку, только если `|depth_card − depth| < 0.06` (допуск в долях AABB) и тексел не пуст; результат — взвешенная сумма принятых граней; если ни одна не принята — прежний путь (`albedo` объёма + прошлый кадр проб). Зеркало `face_weights/project_to_card` в WGSL ↔ Rust (комментарий «держать в синхроне»).
- `Renderer::set_gi_cards_enabled(bool)`; выключено — путь GI-01 побитно прежний (тест).

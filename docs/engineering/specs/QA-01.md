# QA-01 — Живая проверка владельцем (чек-лист, не код)

- **Статус:** ждёт владельца (не код); пункты 14–22 добавлены 2026-10-29 после волны 7; код не нужен, агентам не выдаётся.
- **Зависит от:** — . **Блокирует:** решения по задачам, где нужна оценка «на глаз/на слух» (SSR, туман, морфы, адаптивная музыка, GI). **Модель:** не применимо.
- **Исполнитель:** владелец (нужны монитор, звук, геймпад). **Размер:** ≈ 45 минут.
- **Зачем:** тесты и кадры без окна не заменяют глаза и уши. Ниже то, что не проверялось вживую.
- **Как сообщать:** по каждому пункту «ок / не ок + что видно или слышно». Для «не ок» приложите скриншот или опишите шаги.

## Запуск
```bash
cargo run --example courier -p redox_core --release
```
```bash
cargo run --example foxrun -p redox_core --release
```

## Courier
| # | Что проверить | Ожидание |
|---|---|---|
| 1 | Главное меню → «Настройки» | Экран открывается; ползунок громкости и 4 переключателя читаются, фокус виден |
| 2 | Громкость в настройках | Слышно изменение на лету; после перезапуска значение сохранено |
| 3 | F1–F4 | Совпадают с переключателями на экране настроек (после F-клавиши экран показывает то же) |
| 4 | Игра с геймпада: стик, прыжок, пауза | Управление отзывчивое; меню навигируется геймпадом |
| 5 | Подбор монеты | Есть звук; счётчик растёт один раз на монету (логика монет теперь в WASM-модуле) |
| 6 | Музыка | Играет, зацикливается; при смене экрана кроссфейд без щелчков |
| 7 | F5 | Слева внизу полупрозрачная панель «textures / meshes / shadows / …»; обновляется ~2 раза в секунду; повторное F5 прячет |
| 8 | Ресайз окна, сворачивание | Нет чёрного кадра, текст панелей остаётся чётким |

## Волна 7 (добавлено 2026-10-29)
| # | Что проверить | Ожидание |
|---|---|---|
| 14 | SSR (`renderer.set_ssr(Some(SsrSettings::default()))` в любом примере с глянцевым полом) | Пол отражает объекты на экране; на краях экрана отражение плавно исчезает; нет мерцания |
| 15 | Высотный туман (`set_fog(Some(FogSettings::default()))`, `sun_scatter > 0`) | Туман гуще у земли, лучи солнца видны (и сквозь стены — известное упрощение), без полос |
| 16 | Coat / анизотропия (материал с `coat_weight > 0`) | Слой лака даёт второй блик, металл с анизотропией растягивает блик по направлению |
| 17 | Морфы (лицо с блендшейпами из Blender → glTF) | Веса меняют форму; GPU и CPU выглядят одинаково (`ANM-03`) |
| 18 | Эмиттеры звука с окклюзией (AUD-05) | За стеной звук приглушён, при обходе стены плавно возвращается; шаги/эффекты не обрезаются |
| 19 | Адаптивная музыка (нужны стемы) | Слои включаются плавно по параметру, нет щелчков и пропадания ритма |
| 20 | Motion blur и DoF (`PostFxSettings`) | Размытие следует движению; фокус по расстоянию; выключенные эффекты не меняют картинку |
| 21 | Навигация (`nav` примеры/spike) | Агенты обходят друг друга и препятствия, не застревают; цель по скорости (1 мс) — см. NAV-05 |
| 22 | GI / пробы отражений (после GI-01…04, RFL-01) | Свет «отскакивает» от цветных стен, углы не светятся сквозь стены, отражения в комнате показывают комнату |

## Что делать с результатами
Каждое «не ок» → отдельная строка в `docs/engineering/BACKLOG.md` (раздел 1) с ID вида `BUG-NN`, и спецификация пишется под конкретный симптом.

# GI-01 — G1: DDGI по глобальному SDF (многократные отражения света, пробы с видимостью)

- **Статус:** шаги 1–4 написаны (код и тесты, без компиляции и без запуска cargo: проверка координатором после слияния). Шаг 5 не начат: остановлен после шага 4 как слишком рискованный без компиляции (правки `pbr.wgsl`/`vg_resolve.wgsl` биндингов, удаление DDGI). Шаг 6 не начат. Отступления и допущения — в отчёте и комментариях `ASSUMPTION:`.

- **Размер:** 6 шагов (S, M, M, M, M, S) ≈ 15–18 дней. **Крейт:** `redox_render`. **Зависит от:** RFL-01 шаг 1 (поднятые лимиты текстур; без него не хватит привязок). **Блокирует:** GI-02, GI-03, GI-04.
- **Модель:** haiku по шагам 1, 2, 6; шаги 3–5 (шейдеры трассировки и обновления, выборка) — haiku с проверкой координатора после каждого шага.
- Цель плана: свет «отскакивает» (красная стена красит соседний пол), тёмные комнаты освещаются, GI ≤ 2,5 мс на 1080p (RTX 4060 Ti, среднее качество). **Не входит:** точечные источники в точке попадания (GI-02), динамические объекты в трассировке (только статика), аппаратные лучи (G5).

## Суть и аудит (по коду на 2026-10-29)
Сейчас `gi/ddgi.rs` + `gi/ddgi_gpu.rs` + `shaders/ddgi_trace.wgsl` — **заготовка**, не GI:
- 8 лучей на пробу (октаэдр 2×4) против ≤ 256 AABB объектов (`MAX_TRACE_BOXES`), попадание = «заслонено» (чёрное), промах = только солнце×0,12;
- нет света в точке попадания, нет многократных отскоков, нет видимости (Chebyshev), нет гистерезиса (проба перезаписывается каждый кадр), сетка фиксирована 8×4×8 вокруг начала координат;
- в `pbr.wgsl` (`ddgi_sample_irradiance`, строки ~207–280) читается `ddgi_probes: array<DdgiProbeGpu>` (storage, биндинг 16–17 группы 1).
Есть и пригодное: `sdf/` (запечённые кирпичи `SdfBrick` 64³ в мировых осях, **без поворота**; `SdfBrickAtlas`; GPU-атлас 128³ на ≤ 8 кирпичей — для теней `sdf_shadow`), кадровый граф с проходом `ddgi_fill` (`frame_graph.rs:48`, `renderer/frame.rs:254 pass_ddgi_fill`), `ShadowClass::Static` у `RenderObject` (RND-08), GPU-таймеры `profiler.rs`.
Решение «оптимально»: **один глобальный SDF-объём вокруг камеры (клипмап позже), собираемый на CPU из статики; трассировка сферическим шагом; освещённость в точке попадания: прямое солнце + эмиссия + прошлый кадр проб (многократный отскок); хранение — октаэдрические текстуры освещённости 8×8 и видимости 16×16 с каймой; гистерезис; 2 каскада**.

## Шаг 2 — глобальный SDF-объём (M)
- `src/sdf/global.rs`: `GlobalSdf { origin: Vec3, voxel: f32, dims: [u32;3] /*по умолчанию 128³*/, distance: Vec<f32>, albedo: Vec<[u8;4]> }`, `MAX_DISTANCE: f32 = 8.0`.
  - `GlobalSdf::from_boxes(boxes: &[RefBox-подобный тип], bounds: Aabb, dims) -> Self` — **точный** SDF (для тестов, стен уровня, простых комнат). Тип боксов — общий с `RefBox` (перенести `RefBox` в `sdf/global.rs` как `SdfBox`, `sdf_ref.rs` использует его).
  - `GlobalSdf::from_bricks(bricks: &[(SdfBrick, [f32;4] /*цвет объекта rgba; a = эмиссия*/)], bounds, dims)` — для каждого вокселя: минимум по кирпичам, чей домен содержит воксель (`SdfBrick::sample_world`), иначе `расстояние до AABB кирпича` (нижняя оценка), ограничить `MAX_DISTANCE`; цикл по вокселям ограничен диапазоном AABB кирпича + запас, а не по всему объёму. Альбедо вокселя = цвет ближайшего кирпича.
  - `sample(&self, p: Vec3) -> f32` (трилинейно, зеркало WGSL), `albedo_at(p)`.
  - Кодирование: расстояние `R16Float` через `half::f16` (**ПРОВЕРИТЬ** `grep half crates/redox_render/Cargo.toml`; нет — взять из `Cargo.lock` версию, уже стоящую в дереве, и добавить в `[dependencies]` без новых загрузок; иначе написать `f32_to_f16_bits` с тестом на 1000 значений против эталонных), альбедо `Rgba8Unorm`.
- GPU: `GlobalSdfGpu { distance_tex: texture_3d R16Float, albedo_tex: texture_3d Rgba8Unorm, info: uniform { origin_voxel: vec4, dims: vec4<u32> } }`, `upload(&mut self, queue, &GlobalSdf)`; учёт памяти (категория текстур, строка «global_sdf»: 128³ × (2+4) байт = 12,6 МБ).
- Сборка из сцены: `Renderer::set_gi_static_geometry(&mut self, boxes: &[SdfBox])` и `Renderer::set_gi_static_bricks(&mut self, &[(SdfBrick, [f32;4])])` — обе пересобирают объём **в фоновом потоке** (`std::thread::spawn`, результат через `mpsc`; пока сборка идёт, GI использует прежний объём), вызываются игрой при загрузке уровня. Объекты с поворотом кирпичами не представить: документировать в doc-комментарии, предупреждение в лог.

## Шаг 3 — трассировка проб на GPU (M)
- `shaders/gi_trace.wgsl` (новый; старый `ddgi_trace.wgsl` остаётся до шага 5): `@compute @workgroup_size(64)`; на нить — один луч; `dispatch = probe_count × RAYS_PER_PROBE / 64`. `RAYS_PER_PROBE = 64` (uniform: 32/64/128 по качеству).
- Направления: сфера Фибоначчи `fib_dir(i, n)`, случайно повёрнутая на кадр (поворот из `frame_index` через хеш, чтобы лучи не повторялись); зеркало на CPU `fibonacci_sphere(i, n)` в `gi/oct.rs` (тест).
- Сферический шаг по `distance_tex` (`textureSampleLevel`, трилинейно): до 48 шагов, `t_max = 40 м`, `eps = 0.5*voxel`; промах → радиация неба: `textureSampleLevel(t_prefiltered, …, dir, 4.0)` (самый размытый мип глобальной карты, чтобы не заводить ещё привязку).
- Попадание: нормаль по градиенту SDF (6 выборок); `albedo`, `emissive` из `albedo_tex` (`a * 16`); прямое солнце: тест видимости вторым сферическим лучом к солнцу (`sun_dir`), вклад `sun_rad * max(dot(n, l), 0) * albedo / π`; многократный отскок: освещённость прошлого кадра из атласа проб в точке попадания (та же функция выборки, что в шаге 5, но **без** видимости — дёшево) × albedo; сумма `radiance = emissive + direct + bounce`.
- Выход: `ray_data: array<vec4<f32>>` (rgb радиация, w = расстояние попадания или `t_max` при промахе), индекс `probe * RAYS + ray`.
- Rust: `src/gi/trace.rs` — `GiTracer { pipeline, bgl, ray_buffer, params }`, `record(encoder, probes_count, rays, frame_index)`. Буфер `ray_data` = `probe_count × 128 × 16` байт максимум (для 2 каскадов 2×(16·8·16) = 4096 проб → 8 МБ).
Тесты (GPU, `tests/gi_trace.rs`; сцена = `cornell_box()` через `GlobalSdf::from_boxes`):

## Шаг 4 — интеграция в текстуры проб (M)
- Атлас освещённости: `Rgba16Float`, на пробу `8×8` + кайма 1 = `10×10` текселей; проба `i` лежит в сетке `ceil(sqrt(N))`. Атлас видимости: `Rg16Float`, `16×16` + кайма = `18×18` (среднее расстояние и квадрат расстояния).
- `shaders/gi_update.wgsl` — два входа: `update_irradiance` и `update_visibility` (по нити на тексель, группа 8×8): для тексела направление `oct_decode`, суммирование лучей из `ray_data` с весом `max(0, dot(texel_dir, ray_dir))^K` (`K = 1` для освещённости, `K = 50` для расстояния; расстояние ограничить `0.75*max_probe_distance`), `new = mix(old, accum, 1 - hysteresis)`, `hysteresis = 0.97` (константа в uniform; **0.9, если освещение сильно изменилось**: определять на CPU по сдвигу солнца > 2° или `set_gi_static_*` → следующие 8 кадров hysteresis 0,8). Освещённость хранить в «перцептивном» виде: `pow(accum, 1/5)` и обратно при чтении (как в DDGI), чтобы не мерцало.
- `shaders/gi_borders.wgsl`: копирует каймы (зеркально по октаэдру) — иначе билинейная выборка на краях даёт швы. Зеркало формулы кромки на CPU `border_source(texel) -> texel` в `gi/oct.rs` + тест.
- Rust: `src/gi/atlas.rs` — `ProbeAtlas { irradiance: Texture, visibility: Texture, probes_per_row }`, `texel_origin(probe) -> [u32;2]`, `uv_for(probe, dir) -> [f32;2]` (с учётом каймы), `record_update(encoder, …)`.

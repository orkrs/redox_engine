# EDT-B2 — Редактор, этап B, срез B2: компоненты и массовое редактирование

- **Статус:** не начат.
- **Размер:** 4 шага (M, M, M, S) ≈ 3–4 дня. **Крейты:** `redox_reflect`, `redox_editor_core`, `redox_editor_ui`, крейты компонентов (`redox_physics`, `redox_audio`, `redox_render`, `redox_scene`). **Зависит от:** EDT-A3 (транзакции), A5 (метаданные, InspectorModel), A8 (ссылки на ассеты, желательно). **Блокирует:** B7 (fix зависимостей компонентов).
- **Исполнение:** агент (haiku) без cargo; координатор после шагов.
- Источник: `EDITOR_PLAN.md` §6 B2; ТЗ §5.
- **Не входит:** редакторы mesh/texture (отдельные срезы D), кастомные property drawers плагинов (C6).

## Суть
После A5 Inspector умеет метаданные и mixed-value, но повседневные операции «добавить/удалить/скопировать компонент», поиск по категориям и предупреждения о зависимостях ещё не оформлены как единый workflow с Undo.

## Что уже есть
- `inspector_model` / `InspectorPanel` (A5): секции, фильтр, reset, multi-edit.
- `UndoCommand::{AddComponent,RemoveComponent,SetComponent}` (A3).
- `TypeRegistry` с зарегистрированными компонентами сцены/физики (A2/A5).

## Шаг 1 — каталог компонентов (M)
- `ComponentCatalog` в `redox_editor_core`: список типов из registry с `category`, `tooltip`, поиском; исключает `hidden` / editor-internal по метаданным.
- Зависимости (декларативно): таблица или атрибут `#[reflect(requires = "Transform")]` — минимальный набор для физики (`Collider` требует `RigidBody` или предупреждает).
- Тесты: поиск по категории; requires срабатывает на фикстуре.

## Шаг 2 — add/remove/copy через Undo (M)
- Команды `component_add`, `component_remove`, `component_copy_values` (копия выбранных полей с источника на targets) — одна транзакция на операцию.
- При add зависимого без базы — `Warn` в лог + диалог Continue/Cancel (логика без окна в `file_state`-стиле чистой функции).
- Тесты: add+Undo; remove+Undo восстанавливает значение; copy values на 3 сущности одной транзакцией.

## Шаг 3 — UI Inspector / меню (M)
- Кнопки Add Component (поиск по каталогу), Remove, Copy from…, Reset (уже A5).
- Мультивыбор: mixed + применение одного значения (A5) покрыто; здесь — массовый add одного типа всем выделенным (пропуск уже имеющих).
- Тесты модели: bulk add пропускает существующие; счётчик транзакций = 1.

## Шаг 4 — регистрация оставшихся gameplay-компонентов (S)
- Зарегистрировать недостающие безопасные для сцены типы из `redox_gameplay` / audio (только те, что уже `Reflect`); остальное 📌 в отчёте.
- Документ: список зарегистрированных категорий в `docs/engineering/notes/EDT-B2-report.md`.

## Границы
- **Читать:** `inspector*`, `undo.rs`, `reflect` derive.
- **Создать:** `component_catalog.rs`, тесты.
- **Менять:** inspector UI, builtin commands.
- **Не трогать:** viewport, asset import.

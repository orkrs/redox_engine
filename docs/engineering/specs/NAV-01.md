# NAV-01 — Навигация, шаг 0: каркас крейта `redox_nav` и двухдневный spike (`rerecast` + `landmass`)

- **Размер:** M (2 дня, жёсткий таймбокс). **Крейты:** новый `redox_nav`; корневой `Cargo.toml`. **Зависит от:** ADR 0007 (решения ниже), ответов владельца. **Блокирует:** NAV-02, NAV-03, NAV-04.
- **Модель:** haiku для каркаса и измерений; **вывод «годится / не годится» делает координатор** по таблице результатов, а не исполнитель.
- Ничего из `rerecast`/`landmass`/`dodgy_2d` не видно за пределами `redox_nav`.

## Принятые допущения (ответы по ADR 0007; владелец может изменить любое — спеки NAV-02…04 тогда обновляются)
| Вопрос ADR | Допущение по умолчанию | Почему |
|---|---|---|
| 1. Вторая версия `glam` в дереве (`cargo deny` предупреждает) | **Да, допустимо** | `multiple-versions = "warn"`; конвертация на границе — копия массива |
| 2. Летающие/плавающие агенты | **Нет** (только земля) | обе игры наземные; `dodgy_3d` не нужен |
| 3. Классы агентов на старте | **Один** (радиус 0,4 м, высота 1,8 м, шаг 0,4 м, склон 45°); API сразу принимает `AgentClass(u8)` | каждый класс = отдельная запечка; второй класс — отдельная мелкая задача |
| 4. Рантайм-запекание | **Только заранее запечённые плитки** + пересборка одной плитки при малых изменениях | бюджет кадра на запекание большого уровня не проверен |
| 5. Off-mesh связи | **Из кода / файла сцены**, без редактора | редактор — отдельный проект |
| 6. Цель «200 агентов < 1 мс» | **Одно ядро**, release, референс-машина владельца | строже; пул потоков — запасной выход |
Если владелец не согласен хотя бы с одним — остановиться и вернуть вопрос координатору.

## Суть
ADR 0007 решил: запекание — `rerecast` 0.4, пути и избегание — `landmass` 0.9 (`dodgy_2d` внутри), всё за собственным фасадом. Но в ADR много пометок «unverified»: API плиток `rerecast` не описан на docs.rs,
стыки плиток `landmass` видны только в исходниках, производительность на 200 агентах не измерена. Прежде чем писать NAV-02…04, нужны **два дня** на проверку и таблица фактов.

## Что сделать
### 1. Каркас (S)
- Крейт `crates/redox_nav` (lib, edition 2024, MSRV 1.95, `#![forbid(unsafe_code)]`, `#![warn(missing_docs)]` как в соседних крейтах — **ПРОВЕРИТЬ** `crates/redox_audio/src/lib.rs` шапку), добавить в `members` (`Cargo.toml:3`).
- Зависимости (точные версии, `default-features = false`): `rerecast = "0.4"` (features `libm`, `serde` — **ПРОВЕРИТЬ** имена в `Cargo.toml` крейта: `cargo add rerecast --dry-run`/исходник в `~/.cargo/registry/src`), `landmass = "0.9"`, `redox_math` (path).
  `landmass` тянет `dodgy_2d`. `bevy_*` не подключать.
- `cargo deny check` и `cargo tree -d` — вывод в отчёт; если `deny` падает (лицензия/запрет) — остановиться и сообщить.
- `python scripts/gen_crates_doc.py` — обновить `docs/CRATES.md` и закоммитить.
- Фасад-заглушка `src/lib.rs`: `pub struct NavWorld;` и документ-комментарий; ничего больше.

### 2. Spike A — запекание (rerecast), день 1
Файл `crates/redox_nav/examples/spike_bake.rs` (пример, не часть публичного API). Входные данные: три сцены из кода (треугольники массивами):
(a) комната 10×10 м с проёмом 1,2 м; (b) лестница из 8 ступеней высотой 0,15 м; (c) пол 40×40 м, разрезанный на плитки 16 м с границей.
Для каждой: сконфигурировать (радиус 0,4, высота 1,8, шаг 0,4, склон 45°, размер ячейки 0,2 / 0,1), запечь, вывести: число полигонов, число вершин, время. Для (c) — запечь **по плиткам** и проверить, что соседние плитки делят рёбра (общие вершины в пределах 1e-3).
Определить **определённость**: запечь дважды, сравнить сериализованный вывод побитно; повторить из другого потока.
Записать фактические сигнатуры API (как задаётся `Config`, как подаются плитки/`aabb`/`border_size`, что возвращается) в `docs/engineering/notes/nav-spike.md`.

### 3. Spike B — пути (landmass), день 2
Файл `examples/spike_paths.rs`. На сетке из Spike A (a) и (c):
- создать `Archipelago`, острова = плитки; проверить: путь через границу плиток, замена острова без телепорта агента, стоимость по типу полигона (болото ×3 → путь обходит), `AnimationLink` (off-mesh), недостижимая цель → ответа «нет пути».
- 1000 запросов пути между случайными точками на (c): среднее и p99 (мкс).
- 200 агентов с избеганием идут через проём 1,2 м к общей цели: шагов до достижения, время обновления одного кадра (мс; release; одно ядро), число застрявших.
- Агенты двух радиусов (0,4 и 0,8) в одном `Archipelago`: поддерживается ли (да/нет).
Дописать факты в `docs/engineering/notes/nav-spike.md`.

## 2. Ключи кэша пайплайнов

`shader/mod.rs` не содержит `ShaderKey` и `Features`: шейдеры компилируются из встроенных строк (`PBR_WGSL` и др.), пайплайны создаются в структурах проходов. `pipeline_cache.rs` — это кэш драйвера wgpu, не ключ по материалу. Новый вариант пайплайна — это новое поле прохода, а не новый ключ.

## 3. Как VG обходит материал

`renderer/assets.rs:161-164`: материалы с `alpha_test` помечаются `vg.mark_alpha_tested_material`, и их меши не регистрируются как VG. `renderer/scene_sync.rs:139` делает то же по `material_alpha_test` (файл принадлежит FOL-01, не трогаю). VG-пайплайны не меняются.

## 4. Варианты

- **A. Пайплайн на `double_sided`.** Для прохода PBR создаётся второй пайплайн с `cull_mode: None`. Выбор в `renderer/draw.rs` по материалу, по образцу `shadow/masked.rs` и `is_masked` в `renderer/contexts.rs`. Лицевые пайплайны не меняются. В шейдере переворот нормали и тангента по `front_facing` только при бите `DOUBLE_SIDED`.
- **B. `cull None` везде + `discard` задней грани в шейдере для односторонних.** Требует `cull None` в каждом пайплайне (pbr, normal, velocity, depth, графы, transparent). Для односторонних каждый фрагментный шейдер получает `discard` по `front_facing`. Это отключает early-z для всей непрозрачной геометрии, а нужные проходы (depth, velocity) не получают доступ к флагу материала без новых биндингов.

## 5. Выбор: A

Критерий спеки: меньше кода и ни одного изменения кадра для односторонних. Вариант A не трогает ни один односторонний пайплайн: кадр для односторонних материалов идёт тем же путём, что и раньше, а в шейдере новый код выключен флагом. Вариант B меняет cull у всех проходов и вносит `discard` в путь для всех материалов, что по определению меняет путь выполнения для односторонних, хотя результат и должен совпасть. A также повторяет уже работающий в проекте образец вариантов по материалу (тени вырезных), то есть объём кода меньше.

Ограничения варианта A, которые фиксирую для шага 2 и координатора:
- Шаг 2 покрывает прямой проход PBR (основной путь). Префасс нормалей, velocity и теневые проходы для двусторонних материалов пока по-прежнему отсекают заднюю грань. Это вариант A, распространённый на остальные проходы, и он уйдёт в отдельный шаг, если координатор решит.
- Материалы графов (MAT-02) не получают флаг: их шейдеры собираются отдельно.
- Двусторонние материалы исключаются из VG (как `alpha_test`), VG не трогаю.

**Находки при написании спек (важны для планирования):**
- Туман (PST-06) в движке отсутствует полностью; SSR (PST-05) невозможен без roughness — выбран вариант «второй вывод префасса через `ModelUniform`».
- Тени (RND-08): кэш страниц и инвалидация по AABB уже есть; дефект — эвристика «динамика = малый по размеру объект» и хрупкое сравнение центров по индексу.
- GPU-сцена (RND-07): индексация `storage`-буфера моделей и склейка пробегов уже есть; indirect не уменьшит число вызовов записи, пока материалы привязаны по bind group на группу — главная оговорка шага 2.
- Морфы (ANM-02): ассет для тестов не нужен — `.glb` собирается в памяти (как для тангентов).
- Материалы: **E1 (`material_surface`) не сделан** — без него E2…E7 неосуществимы, поэтому оформлен MAT-01; «Substrate» в коде — взвешенная сумма лепестков, не слои (MAT-04).
- VG: двухпроходный Hi-Z и indirect уже есть (VG-02 опирается на них); `meshopt` уже в зависимостях (VG-01).
